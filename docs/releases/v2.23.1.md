# v2.23.1 — Karbantartás: az utazási figyelmeztetések adaptere nem importál a `lib/`-ből / Maintenance: the travel-advisories adapter no longer imports from `lib/`

## Magyar

- **Mi változott:** a [v2.19.0](v2.19.0.md) `Travel-Advisories` adaptere közvetlenül a `lib/intelligence/countries.mjs`-ből oldotta fel az országneveket. A projekt szabálya, hogy a forrás-adapterek nem importálnak a `lib/`-ből (a térképezés a `lib/` oldalán történik). Mostantól az adapter az **országnevet** adja át, ahogy az USA külügyminisztériuma írja (a „Travel Advisory" utótag levágva, `__proto__`-szerű kulcsok kizárva), és a kockázati lépés ([lib/intelligence/risk-step.mjs](../../lib/intelligence/risk-step.mjs)) képezi le az ISO3 kódra (a két alias, a „The Kyrgyz Republic" és a „Kingdom of Denmark" is itt él).
- **Viselkedés:** változatlan. A kockázati bemenet, az API (`advisory`), az országlap és a pontszámok ugyanazok; a 212 ország ugyanúgy feloldódik. Az adapter kimenetében a `countries` kulcsa mostantól a név, nem az ISO3 kód (belső forma, a felület nem látja).
- **Ellenőrzés:** a meglévő 5 tesztet igazítottam a névalapú kimenethez (a kulcsok nevek; az alias a kockázati bemeneten át ellenőrzött; egy `__proto__` című tétel sosem lesz kulcs). Futtatva: a forrás-regisztert használó fájlok (tartomány, élő-lánc, élő-regiszter, élő-forrás-integráció, lencse, paletta, egészségmátrix, szerkezet, változások, óra, sweep-archívum, visszajátszás, riasztás-alap, forrás-elérhetőség, környezet, nyelvi fájlok) és az utazási/GNSS-tesztek: 408 teszt, 0 hibás; `npm run check` rendben.

## English

- **What changed:** the `Travel-Advisories` adapter of [v2.19.0](v2.19.0.md) resolved country names straight from `lib/intelligence/countries.mjs`. The project's rule is that source adapters do not import from `lib/` (the mapping happens on the `lib/` side). The adapter now hands over the **country name** as the U.S. State Department writes it (the "Travel Advisory" suffix cut, keys like `__proto__` excluded), and the risk step ([lib/intelligence/risk-step.mjs](../../lib/intelligence/risk-step.mjs)) maps it to the ISO3 code (the two aliases, "The Kyrgyz Republic" and "Kingdom of Denmark", live there too).
- **Behaviour:** unchanged. The risk input, the API (`advisory`), the country sheet and the scores are the same; the 212 countries resolve the same way. In the adapter's output the `countries` key is now the name, not the ISO3 code (an internal shape, not visible in the interface).
- **Validation:** the existing 5 tests were adjusted to the name-based output (keys are names; the alias is checked through the risk input; an item titled `__proto__` never becomes a key). Run: the files that use the source registry (domains, live-chain, live-registry, live-sources-integration, lens, palette, health-matrix, structure, changes, clock, sweep archive, replay, alert foundation, source availability, env, locales) and the travel and GNSS tests: 408 tests, 0 failed; `npm run check` passes.
