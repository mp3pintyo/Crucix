# v2.37.0 — Ellenőrzött PR-integráció / Reviewed PR integration

## Magyar

14 saját és 50 upstream PR kapott külön, rögzített headre vonatkozó döntést. A saját #2–14 integrálva; #14 a #4 duplikátuma. A részletes vizsgálat és a tesztelés korlátai: [PR-jegyzőkönyv](../audit/pr-review-2026-10-10.md).

- Élő AIS hajóadatok és szövegként megjelenített hajójelölők; a lejárt jelölők a szerveren és az offline böngészőnézetben is eltűnnek.
- OpenSky OAuth klienshitelesítés, határolt tokenkérés, gyorsítótár és 429-kezelés; ütemezett, gyorsítótárazott Comtrade-lekérések.

- Magyar/francia jelmagyarázat, országnevek, exportok és riasztási hibák; környezeti nyelvbetöltés és Telegram-javítás. A hőanomália-eszkaláció és a fenyegetési idővonal megmarad.
- RIPEstat frissesség: azonos 12 órás ablak a szerveren és a böngészőben.

A saját #15 kimarad a korlátlan RSS-válaszok, párhuzamos kérések erőforrásigénye, elavult gyorsítótár és további igazolatlan működés miatt. Az upstream #27 obfuszkált távoli kódfuttató részt tartalmaz; nem futtattuk és nem integráltuk. Az upstream #103 nagy átalakítása és más új szolgáltatások külön javítást/ellenőrzést igényelnek. A már meglévő upstream javításokat nem vezettük be még egyszer.

Ellenőrzés: Windows / Node 24 alatt **1662 sikeres teszt, 0 hiba, 1 kihagyott**, sikeres szintaxis/nyelvi ellenőrzés és függőségi audit (0 jelzett sérülékenység). A kihagyott teszt élő OpenRouter-hitelesítést igényel. A saját PR-headek külön teljes tesztet kaptak. Veszélyes upstream kódot nem futtattunk; a jegyzőkönyv külön jelöli a statikus vizsgálatot, szintaxisellenőrzést és regressziót. Ez nem minden külső API élő ellenőrzése, és nem kockázatmentességi garancia.

## English

14 fork and 50 upstream PRs received individual pinned-head decisions. Fork #2–14 are integrated; #14 duplicates #4. See the [review ledger](../audit/pr-review-2026-10-10.md) for evidence and coverage limits.

- Live AIS collection and text-only vessel markers, withdrawn when expired on server and restored offline/browser views.
- OpenSky client-credentials OAuth with bounded token exchange, caching and 429 handling; paced, cached Comtrade requests.
- Anthropic gateway/bearer authentication, blocked redirects, a 2 MiB response cap and error messages that do not echo secrets.
- Shared bounded LLM JSON extraction, fenced/capped OSINT context and consistent idea output.
- Hungarian/French signal guide, country display names, exports and alert errors; environment language initialization and Telegram fixes. Thermal escalation and the threat timeline are preserved.
- Consistent 12-hour RIPEstat freshness in browser and server.

Fork #15 is withheld for unbounded RSS responses, request amplification, stale restored cache and remaining validation gaps. Upstream #27 contains obfuscated remote execution logic; it was never executed or integrated. The large upstream #103 rewrite and other new integrations require repair/further validation. Existing upstream fixes were not reintroduced.

Validation: **1662 passed, 0 failed, 1 skipped** on Windows / Node 24, successful syntax/locale checks and dependency audit (0 reported vulnerabilities). The skipped test requires live OpenRouter credentials. Each fork head received full tests separately. Unsafe upstream code was not executed; the ledger distinguishes static review, syntax-only checks and regression tests. External services were fixture-tested; this is not a guarantee of zero risk.
