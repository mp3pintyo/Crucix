# v2.16.1 — CI-javítás: rögzített forrásszám a paletta-tesztben / CI fix: a pinned source count in the palette test

## Magyar

- **Tünet:** a [v2.15.0](v2.15.0.md) és a [v2.16.0](v2.16.0.md) GitHub CI-futása piros lett: `page: paletteSources has one item per source of the domain registry` – a teszt a forrásregiszter méretét kézzel beírt számként (52) is ellenőrizte, a két új kiberforrással pedig 54, a MISP Galaxyvel 55 lett. A piros tag-futás miatt a két kiadáshoz Docker-kép nem készült.
- **Gyökérok:** a teszt két ellenőrzése közül az egyik (`list.length === names.length`) már magától követi a regisztert, a másik (`=== 52`) minden új forrásnál elavul. Az én hibám: a v2.15.0-nál a forrásregisztert használó tesztek közül ezt a fájlt nem futtattam le.
- **Javítás:** a kézzel beírt szám törölve, a regiszterből számolt ellenőrzés marad ([test/palette.test.mjs](../../test/palette.test.mjs)). Termékkód nem változott; a v2.15.0 és v2.16.0 változtatásai ebben a kiadásban élnek tovább.
- **Ellenőrzés:** a regisztert használó tesztek közül a paletta, a visszajátszás-archívum, az óra és a változások tesztje: 170 teszt, 0 hibás (a korábbi kiadások jegyzeteiben már futtatott lencse-, tartomány-, élő-forrás-, egészségmátrix- és szerkezeti tesztekkel együtt a regisztert használó összes tesztfájl lefutott). `npm run check` rendben.

## English

- **Symptom:** the GitHub CI runs of [v2.15.0](v2.15.0.md) and [v2.16.0](v2.16.0.md) went red: `page: paletteSources has one item per source of the domain registry`. The test also checked the registry size against a hand-typed number (52); with the two new cyber sources it became 54, with MISP Galaxy 55. Because the tag runs were red, no Docker image was built for either release.
- **Root cause:** of the test's two checks, one (`list.length === names.length`) follows the registry by itself, while the other (`=== 52`) goes stale with every new source. My mistake: for v2.15.0 I did not run this file among the tests that use the source registry.
- **Fix:** the hand-typed number is gone; the check computed from the registry stays ([test/palette.test.mjs](../../test/palette.test.mjs)). No product code changed; the changes of v2.15.0 and v2.16.0 live on in this release.
- **Validation:** of the tests that use the registry, the palette, replay-archive, clock and changes tests: 170 tests, 0 failed (together with the lens, domain, live-source, health-matrix and structure tests already run for the earlier releases, every test file that uses the registry has now run). `npm run check` passes.
