# v2.30.1 — Javítás: a figyelőlista-teszt szintaxishibája / Fix: a syntax error in the watchlist test

## Magyar

A v2.30.0 kiadásban a [test/watchlist.test.mjs](../../test/watchlist.test.mjs) egyik sora (a God's Eye View átnézett állapotát ellenőrző állítás) szintaxishibás volt: egy szövegben lévő aposztróf lezárta az idézőjelet, így a tesztfájl nem töltődött be. A kiadás kódja (credits.js, oldal, nyelvi kulcsok) nem érintett; a hibát a tag előtti ellenőrzésem nem fogta meg, mert a kiadási parancsláncban a teszt kimenete nem állította meg a commitot. Javítva (a szöveg tipografikus aposztrófot használ). Futtatva: a watchlist-teszt (2 teszt, 0 hibás), `npm run check`.

## English

In v2.30.0 one line of [test/watchlist.test.mjs](../../test/watchlist.test.mjs) (the assertion that checks the reviewed state of God's Eye View) had a syntax error: an apostrophe in a string closed the quote, so the test file did not load. The release code (credits.js, the page, the locale keys) is not affected; my pre-tag check missed the error because in the release command chain the test output did not stop the commit. Fixed (the text uses a typographic apostrophe). Run: the watchlist test (2 tests, 0 failed), `npm run check`.
