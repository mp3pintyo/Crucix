# v2.30.2 — Javítás: a rögzített előzményszűrő-tesztek ismerik az új „launch” fajtát / Fix: the pinned history-filter tests know the new "launch" kind

## Magyar

A v2.27.0 új `launch` eseményfajtája bekerült az előzmények típusszűrőjébe, de két rögzített teszt ([test/intelligence-ui.test.mjs](../../test/intelligence-ui.test.mjs): „a típusszűrő csak az API által támogatott kategóriákat kínálja” és „minden fajtának van angol és helyi címkéje”) még a régi 21 fajtát várta. Ezért a **v2.27.0, v2.28.0 és v2.29.0** kiadás tag-futása piros lett (a Docker-kép kimaradt); a kiadások kódja működik, a hiba csak a tesztek rögzített listája volt. A saját ellenőrző körömből a fájl kimaradt (nem a `jarvis.html`-t használó tesztek közé tartozik): **a tanulság, hogy új eseményfajta után az `intelligence-ui` tesztet is futtatni kell**. A v2.30.0 tag-futása emellett a v2.30.1-ben javított szintaxishiba miatt is piros.
- Javítva: a lista és a darabszám (22). Futtatva: **a teljes csomag, 1509 teszt, 0 hibás** (ez egyszeri teljes futás volt a három piros kiadás miatt), és az új tesztek egy CRLF-es klónban is (73 teszt, 0 hibás, a Windows CI-t utánozva).

## English

The new `launch` event kind of v2.27.0 reached the history type filter, but two pinned tests ([test/intelligence-ui.test.mjs](../../test/intelligence-ui.test.mjs): "the type filter offers only API-supported categories" and "every kind has an English and a local label") still expected the old 21 kinds. That turned the tag runs of **v2.27.0, v2.28.0 and v2.29.0** red (the Docker image was skipped); the code of those releases works, only the tests' pinned lists were stale. The file was missing from my own check set (it does not use `jarvis.html`): **the lesson is that after a new event kind the `intelligence-ui` test must be run too**. The v2.30.0 tag run was also red because of the syntax error fixed in v2.30.1.
- Fixed: the list and the count (22). Run: **the whole suite, 1509 tests, 0 failed** (a one-off full run because of the three red releases), and the new tests in a CRLF clone as well (73 tests, 0 failed, imitating the Windows CI).
