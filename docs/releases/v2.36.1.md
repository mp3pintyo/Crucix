# v2.36.1 — Javítás: a rögzített kockázati összegzés-teszt ismeri az új „timeline” mezőt / Fix: the pinned risk-summary test knows the new "timeline" field

## Magyar

A v2.36.0 mindkét CI-futása (master és tag) piros lett: a `test/intelligence-routes-risk.test.mjs` a `snapshot.risk` kulcsait pontosan rögzíti (`version, at, top, counts, calibration, anomalies`), és a v2.36.0 új `timeline` mezőt adott hozzá. A hiba **csak a teszt listája** volt, a program helyesen működött. A teszt kulcslistája most `…, calibration, anomalies, timeline`.

- **Miért maradt ki?** A v2.36.0 futtatott részhalmazába (kockázati panel + kulcsszó/anomália + regiszter-fogyasztók + a 11 `jarvis.html`-es fájl) nem került bele ez a fájl. A kiadási jegyzet ezt nem állította (a részhalmaz nevesítve volt), de a hiányzó fájlt a CI találta meg. A tanulság: a `snapshot.risk` alakját érintő változásnál az `intelligence-routes-risk` tesztet is le kell futtatni.
- A tag-futás piros volt, ezért a v2.36.0 Docker-képe nem készült el; ez a kiadás a javított teszttel pótolja.
- Ellenőrzés: a kockázathoz tartozó 6 tesztfájl (`intelligence-risk`, `intelligence-routes-risk`, `intelligence-routes`, `keywords-anomalies`, `risk-ui`, `sources-risk`): 18 teszt, mind zöld. A teljes csomagot a CI futtatja.

**GitHub CI:** a branch- és a tag-futás is zöld ([master-futás](https://github.com/mp3pintyo/Crucix/actions/runs/37819233047), [tag-futás](https://github.com/mp3pintyo/Crucix/actions/runs/37819233651)); a Docker-kép elkészült.

## English

Both CI runs of v2.36.0 (master and tag) went red: `test/intelligence-routes-risk.test.mjs` pins the exact keys of `snapshot.risk` (`version, at, top, counts, calibration, anomalies`) and v2.36.0 added a `timeline` field. The fault was **only the test's list**; the program worked correctly. The test's key list is now `…, calibration, anomalies, timeline`.

- **Why was it missed?** The subset run for v2.36.0 (the risk panel + keywords/anomalies + the registry consumers + the 11 `jarvis.html` files) did not include this file. The release notes did not claim otherwise (the subset was named), but CI found the missing file. The lesson: a change to the shape of `snapshot.risk` also needs the `intelligence-routes-risk` test.
- The tag run was red, so no Docker image was built for v2.36.0; this release replaces it with the fixed test.
- Verification: the 6 risk-related test files (`intelligence-risk`, `intelligence-routes-risk`, `intelligence-routes`, `keywords-anomalies`, `risk-ui`, `sources-risk`): 18 tests, all green. The whole suite is run by CI.

**GitHub CI:** both the branch and the tag run are green ([master run](https://github.com/mp3pintyo/Crucix/actions/runs/37819233047), [tag run](https://github.com/mp3pintyo/Crucix/actions/runs/37819233651)); the Docker image was built.
